## Findings (severity-ranked)

1. **MAJOR — FB-061 residual leak (documented known-limit; owner decision).**
   The board still renders soft-deleted QA entities through joins that carry no
   `deleted_at` filter. Row 14: real lot `EBKG18452303`, vehicle column shows
   `15H-021.39 · Nhà vận tải: STG VERIFY NHA XE 09` — chain verified in DB:
   `trip_carrier_info` id 28 (trip 12) → `customers` id 23 `STG VERIFY NHA XE
   09`, soft-deleted 2026-10-04. Row 55 (money-report table): `QA0915 QA-138
   Credit Customer` (0 live / 1 deleted in DB). This is exactly the case doc's
   "Known limit (not closed by this change)" clause. Remedies for the owner:
   (a) filter deleted masters in the board query (behaviour change for real
   data), or (b) targeted scrub of `trip_carrier_info` id 28 + the reports
   join. Not fixed in this run — verify-only.
2. **NOTE — 53 pre-existing QA rows remain on other staging surfaces**
   (`qapurge-dry` census: guarded survivors on ops_expense_entries/advance_
   requests/treasury_accounts/business_units, dispatch_zones 1, sites 10,
   ports 2, …). Not this run's fixtures; the real purge is owner-gated (the
   w3b E2E-carriers ruling is still pending). Dry-run log kept as evidence.
3. **NOTE — driver bugs, not product defects.** Five raw-log FAILs during the
   run were driver defects, each corrected and re-driven green: logger API
   mismatch; container clone-order (rows must be added BEFORE filling — the
   pin-test law); dialog trigger (combinedPicker opens from the field wrapper,
   not the placeholder element); React-Aria selects on the two sweep pages
   (the hidden a11y `<select>` is not the control — drive `input[role=combobox]`
   / `button[aria-haspopup=listbox]` with commit verification); psql stdin
   banner swallowing the first statement (a banner line without `;` made psql
   read the first SELECT into the errored statement).
4. **NOTE — fixture residue.** 12 pricing-family sentinel tombstones remain
   (invisible, slot-reusable by the very fix under test) — the sanctioned
   cleanup path for that class; zero live sentinel rows; no shipments,
   customers or registry-class fixtures were created.
