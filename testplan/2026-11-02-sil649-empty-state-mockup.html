Design Lock Specifications (SIL-649)

1. Stray Stripe Extermination

Root cause: .ts-driver-select had max-width: 260px with no width in a flex toolbar. ComboBox inline-size container collapsed to a 2px border-width stripe at x=1252.

Fix: Assigned explicit width: 260px; min-width: 200px; max-width: 100%. Guarded rendering so when driver list is empty, zero DOM elements are emitted.

2. Month Navigation Container

Replaced floating un-containerized text with a card bar matching .filter-bar--card styling: background: var(--surface); border: 1px solid var(--line); border-radius: 14px; padding: 8px 14px;.

Mobile (<768px): Stacks toolbar vertically with full-width driver picker and space-between month arrows.

3. Centered Empty State Card

Replaced raw single line .ts-hint with .ts-empty-card housing the shared <EmptyState context="salary" /> primitive.

Role-specific CTA: Accountant gets live Mở bảng chấm công action modal trigger; Dispatcher/others get clean guidance text without dead button.
