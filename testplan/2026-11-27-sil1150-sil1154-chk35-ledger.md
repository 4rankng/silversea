## SIL-1150 — row click opens the shared lot editor (`/shipments-detail`)

- QA repro: clicking a cost row on the container board only opened the per-cell «Chỉnh sửa chứng từ và hãng tàu» dialog; no path from the row to the shared lot form.
- KB law: §3.1.7 — the row click must open the shared create-form editor ("ngăn trượt dùng chung mẫu tạo lô").
- Implemented affordance: `ShipmentContainerLedger` gains optional `onOpenLotEditor(row)`; clicking a row OUTSIDE its interactive triggers opens `/shipments/:id/edit` (the create form in edit mode — §3.7.3's shared form). Wired on `ShipmentContainersPage` only; the Ghép bộ Debit board stays inert.
- Deliberate deviation, recorded: the KB sentence says "drawer hosting the create form"; the owner-approved design (SIL-485, 25/10 mockup — CusLotView header) keeps editing OUT of drawers and owns the edit form as a page. The row click therefore lands on the shared editor page; a drawer hosting the full create workspace is an owner decision, not silently built here.
- Cell law intact: per-cell triggers (`SIL-503` — cell click = direct edit) never bubble into the row handler (delegated guard on `button/a/input/select/textarea/label/[role=button]`).

## SIL-1154 + business rule 2 — allocation filter speaks the Q2 3 mức

- BE: `list-summaries` `NOT_ALLOCATED` filter case absorbs the date-locked zero-carrier rows (was: date must be null). `PENDING_CARRIER` keeps its old meaning.
- Supersedes the K4.7/SIL-952 five-bucket bar; plate scope facet (`Đã gán biển / Chưa gán biển`) unchanged.
