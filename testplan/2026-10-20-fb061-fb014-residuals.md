external carrier allocated, driver order issued — filed as *unassigned*.

### Root cause

`listDispatchDetailPlanRows` defined the assignment split purely by the
planned-plate string (`plannedVehiclePlateNumber` empty ⇒ UNASSIGNED). An
external-carrier dispatch whose plate is still pending ("CUS sẽ bổ sung") has
a CREATED trip + issued lệnh but an empty plate string, so the tab counted it
unassigned while the row's own cell rendered the carrier and the phát-lệnh
chip. Staging wire at repro time: UNASSIGNED 49 / ASSIGNED 89, with row 260
(SHP-2609-00244, trip 143, BIỂN XANH, `assignedPlate: null`,
`taskStatus: DISPATCHED`) in the UNASSIGNED page.

Secondary, same class: `trips.status` is free text (`applicationEnum`); a
legacy double-L **'CANCELLED'** trip (staging trips/11, shipment 6) sailed
past the `ne(status, 'CANCELED')` join and hydrated as a phát-lệnh dispatch
(`taskStatus: DISPATCHED` on a canceled trip). Local dev DB carries the same
class as 'IN_PROGRESS' (trips/37088) — any non-enumerated status does.

### Fix (one owner, three consumers)

`backend/src/services/dispatch-detail-plan-assignment-sql.ts` (new) owns the
definition: **ASSIGNED = planned plate set OR live trip**; **UNASSIGNED = its
exact complement**; live trip = `not in ('CANCELED','CANCELLED')` and not
soft-deleted. Consumers:

1. `dispatch-planning-detail-plan-read.service.ts` — quick-tab
   `assignmentPredicate` (rows + pageKeys),
2. both `assignmentStatusCounts` halves (card 20261008_3 partition invariant
   preserved: the halves still sum to the view total),
3. the trips left-join (a legacy 'CANCELLED' trip no longer hydrates a row as
   dispatched; row 6-class renders READY again).

Interpretation note (ticket's letter vs observed defect): the R17 letter said
"chưa biển số"; the tab contract the R24 batch actually tests is "lô đã gán
bị loại đúng" — a carrier-allocated, lệnh-issued row is assigned work. The fix
strictly narrows Chưa gán xe (every old member without a live trip stays), so
the R17 PASS case still holds while the R24 fail state is gone.
