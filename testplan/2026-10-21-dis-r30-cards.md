## dis-03 — kẹp 2 cont 20' báo trùng đầu kéo (FB-012 reopen)

Root cause (chicken-and-egg): trip pairs are created only AFTER both legs
exist, but every rig guard carved only PAIRED partners
(`findActiveKepPairPartner*`). Planning/issuing the second 20' leg therefore
met the first leg's UNPAIRED ACTIVE trip and died on the hard tier with NO
confirm path — exactly "báo trùng đầu kéo". Same-lot legs kept the FB-012
warn; cross-lot legs (QA's R30 shape: two 1×20' lots) dead-ended at
plan-save AND at issue.

Fix (backend):
- `assertPlanRowRigAvailable` — carve the unpaired kẹp candidate (same-plate
  ACTIVE trip whose own fulfillment is DOUBLE, same business day) from
  `tripConflicts`; a single non-Kẹp trip downgrades to the family's warn-once
  (`RIG_OVERLAP_COMPLETED`) instead of the hard tier. Third loads stay hard.
- `assertResourceAvailability` — the mixed-declaration candidate (issuing leg
  Kẹp 20', one same truck+trailer+driver partner whose leg is not Kẹp) carves
  out of `blocking` with the same weight gate, then warns once instead of the
  dead-end "Xe đầu kéo đã bị trùng lịch kế hoạch.".
- FE: `rigOverlapCompletedConfirmed` added to the atomic-save body types
  (it already rode at runtime through the spread).

Regression: `2026-10-21-dis-r30-dis03-kep-repro.mjs` (same-lot warn-once
contract) and `2026-10-21-dis-r30-dis03-crosslot.mjs` (cross-lot Đơn→Kẹp
plan + issue with confirmables). Before/after evidence in
`qa/2026-10-21-dis-r30/`.

## dis-05 — sửa giờ điều xe popup lưu OK nhưng bảng ngoài không refresh

Root cause: `TimePanel`'s exact-time entry committed ONLY on Enter / "Xong".
A mouse user types "1745" and clicks Lưu directly — the picker is dismissed
by the outside pointer press and a removed input never fires blur, so the
typed draft was silently discarded, the save PATCH omitted `plannedEndAt`
entirely ("lưu OK") and the outer grid kept the old hour.

Fix: `TimePanel` records outside presses via a window-capture pointerdown
(ref writes only — no re-render churn under the host modal's own outside-press
path check); when the panel unmounts because of an outside press, valid
changed text commits through the surviving parent chain. Escape keeps the
revert contract (any keydown clears the marker); Enter/"Xong" keep theirs.

Regression: `frontend/src/design-system/forms/TimePanel.mouse-commit.test.tsx`
(4 tests: outside-press commit, Escape revert, invalid text never invents a
time, Enter contract) + the dis-05 phase of the main driver (grid + DB).
