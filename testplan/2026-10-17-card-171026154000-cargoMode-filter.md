# Case 2026-10-17 card 171026154000 — Bảng kế hoạch chi tiết xe: lọc theo loại hàng (FCL/LCL)

- Card: `171026154000-bang-ke-hoach-hang-le-ngoai-trang-1-khong-loc-duoc.docx` (P2)
- Root cause of FB-115's "gán xe nhóm hàng lẻ không thực hiện được" impression.
- Status: OPEN → fixed by this branch.

## Reproduction (pre-fix, real API, measured in the card)

At `/dispatch-detail`, October 2026 scope, role Điều vận:

```
GET /api/shipments/dispatch-detail-plan-rows?page=1&limit=50&dateFrom=2026-10-01&dateTo=2026-10-31
→ total=109  counts={UNASSIGNED:69, ASSIGNED:40}
  page 1: 50 rows {FCL:50, LCL:0}   ← default landing page, 100% cont
  page 2: 50 rows {FCL:10, LCL:40}
  page 3:  9 rows {FCL:5,  LCL:4}
```

All 44 LCL lots live on pages 2–3. The API ignored every attempted filter name:

| Param tried              | Result                                  |
|--------------------------|-----------------------------------------|
| `&cargoMode=LCL`         | 200, total=109, page-1 modes {FCL:50}   |
| `&mode=LCL`              | 200, total=109, page-1 modes {FCL:50}   |
| `&cargoMode[]=LCL`       | 200, total=109, page-1 modes {FCL:50}   |

Data exists (a `/api/shipments` scan of 600 records found 51 LCL lots) — the defect
is access, not data. `DispatchDetailPlanFilters` had no `cargoMode` field.

## Expected behavior (post-fix)

1. `GET .../dispatch-detail-plan-rows?cargoMode=LCL` returns only LCL rows:
   `total` equals the LCL count, every item has `cargoMode: 'LCL'`, and page 1
   contains LCL rows (operator can reach them without pagination).
2. `?cargoMode=FCL` returns only FCL rows (fulfillment branch + điều phối
   fulfillment-less branch, which is inherently FCL).
3. Omitted/empty param: unchanged behavior (both modes, same order) — the filter
   is optional and must not alter the default view.
4. Invalid value (`?cargoMode=XXL`) → 400 with a Vietnamese message.
5. `assignmentStatusCounts` recompute over the cargoMode-filtered set and still
   partition `total` (UNASSIGNED+ASSIGNED = total under the filter).
6. Frontend: a "Loại hàng" select (Tất cả / Cont (FCL) / Hàng lẻ (LCL)) in the
   Bộ lọc nhanh group next to "Điều xe"; it drives the same filter state
   (reset by Xóa lọc / Đặt lại like every other criterion) and reaches the API
   as the `cargoMode` query param.

## Branch semantics pinned by this case

- The fulfillment branch's row `cargoMode` comes from
  `shipment_fulfillments.cargo_mode`, written 1:1 from `shipments.cargo_mode`
  at decomposition (`shipment-fulfillment.service.ts`), so filtering on
  `shipments.cargo_mode` never disagrees with the displayed value.
- LCL lots cannot own containers (decomposition guard), so the fulfillment-less
  branch (container-keyed, hard-renders `cargoMode: 'FCL'`) is empty under
  `cargoMode=LCL` and fully retained under `cargoMode=FCL`.
