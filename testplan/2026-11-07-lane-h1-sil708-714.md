## Fixes

- **SIL-708 leftover** — the QA repro (comment 4352, build `b9f08df4`) found
  the ⋯ menu on `/trips/:id` still rendering "Phân xe lại" wired to the page
  hook's own reassign modal. This lane lands the cleanup in two steps: the
  error-stopped predecessor already deleted the modal body from
  `frontend/src/pages/TripDetailPage.tsx` (salvage commit `cd108aa1`, tsc
  red), and this lane removes everything the modal kept alive —
  `TripHeader`'s `onReassign` prop + menu item + Shuffle icon,
  `TripPermissions.canReassign`, the whole reassign state/handler block in
  `useTripDetailPage` (state, trucks/drivers query, openReassign,
  handleReassign, UI fields, return keys), the now-orphaned
  `TripReassignDialog.tsx` (+ its two test files), and the legacy
  `onOpenTripReassign` prop chain (grid → card list → editor cell → row menu
  — the real surfaces had migrated to `onCancelDispatch`; the fallback was
  dead on every caller). User-facing backend copy that still said "bổ sung
  qua Phân xe lại" now names "Cập nhật biển số"
  (`dispatch-planning-commands.service.ts` PLATE_DEFERRED_CONFIRM 409 +
  `trip-external-close.service.ts` completion 409) with their FE pins.
- **SIL-714** — new trip-scoped pair on the shipments mount (the same
  CUS-admitting shape as `complete-external`, since CUS holds no casbin
  `trips` rows): `GET/PATCH /api/shipments/trips/:tripId/external-plate`,
  `requireRoles(ADMIN, MANAGER, DISPATCHER, CUS)`, material-write declared.
  Service `getExternalTripPlateContext` / `updateExternalTripPlate`
  (`trip-external-close.service.ts`): EXTERNAL-only, live trips only
  (CREATED/IN_TRANSIT — external trips never enter IN_TRANSIT on their own;
  terminal 409), optimistic `trips.version` bump + `trip_carrier_info`
  sidecar upsert in one transaction (lost race = zero bumped rows = 409).
  FE: `shipmentClient.getExternalTripPlateContext/updateExternalTripPlate`,
  shared `TripExternalPlateDialog`
  (`frontend/src/components/trip/`), the `/dispatch-detail` row-menu entry
  gated to awaiting-plate external rows (`canUpdateExternalPlate` in
  `DispatchRowActionsMenu`), the `/shipments-detail` PHÂN XE cell button
  (`canUpdateExternalTripPlate` in `cusUtils` + role helper
  `canUpdateExternalPlates` in `lib/role-access`).
