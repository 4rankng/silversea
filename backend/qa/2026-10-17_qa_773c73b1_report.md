## Severity-Ranked Findings

### Blockers (P0)
*None.* All target surfaces pass specifications.

### High Priority (P1)
*None.*

### Medium Priority (P2)
1. **Unmerge Redundant Snapshots:** When an LCL lot un-merges from a group, the leaver records two duplicate zero-value rows in `freight_rate_snapshots` (`shipment_id | 0` twice). While calculation precision is strictly preserved (0 + 0 = 0), a cleanup migration or upsert refinement should eliminate the redundant snapshot row.

### Low Priority / Informational (P3)
1. **Export Formats Scope:** Ticket 171026004331 references "Debit Note Excel/HTML/PDF export". The production and staging API routes exclusively implement XLSX export (`/shipments/:id/debit-note/export`). Ticket specifications should clarify whether HTML/PDF exports are planned for future epics or if XLSX is the sole intended deliverable.
2. **Phone Pagination vs Desktop Full Table:** The mobile phone card ledger paginates at 20 items per page, whereas desktop renders the full unpaginated table. Reaching specific historical lots on phone view requires explicit URL query parameters (`?customer=&from=&to=`) or search suffix filters.
