Target behaviour
Count all trailers in the declared inventory scope. Reconcile summary, list and assigned-trailer types; represent unknown types explicitly without excluding those records from the total.
Impact
The headline understates trailer inventory, making fleet capacity and type summaries unreliable.
Cause and investigation
Hypothesis: summary aggregation depends on populated trailer types or a different data mapping. Blank legacy types correlate with the discrepancy; the implementation and stored-data cause remain unverified.
Steps to reproduce
1. As Admin, open /fleet and wait for the inventory to settle. Compare the Rơ-moóc summary with the trailer section count and assigned trailers in truck rows.
2. Create a clearly identified 40FT trailer. QA-0914-RM changed the observed summary/list totals from 0/39 to 1/40.
Acceptance criteria
1. The total includes every trailer in the same declared scope, including existing records with unknown types.
2. Type subtotals plus explicitly unknown types reconcile with the total; matching trailer identities show consistent types across sections.
3. Verify existing and newly created records, then refresh and confirm coherent totals. Distinguish loading or unavailable data from a true zero.
4. Keep the existing compact summary layout readable on desktop, tablet and phone.
