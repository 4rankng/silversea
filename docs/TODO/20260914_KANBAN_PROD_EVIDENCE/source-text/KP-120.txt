Restore contrast for the expected profit label in trip creation
QA-121 | P2 | Bug | DEV COMPLETED — chờ deploy staging + QA
Environment: Staging https://vantai.tingting.vip

Role: Admin — desktop and tablet; phone included in regression acceptance

Existing behaviour
The Lợi nhuận dự kiến label is nearly invisible on the pale estimate card, while its +0 value remains green. The same faint label appears in the tablet capture. Live desktop inspection confirmed rgba(255,255,255,0.85) text with a transparent parent at x365, y405.5. The label exists in the accessibility snapshot; this is a visual contrast defect, not a missing value or calculation failure.
Target behaviour
Render the expected-profit label with legible contrast against its actual card background. Keep the label and value visually associated and use a consistent financial-summary text treatment.
Impact
Users can see an amount without being able to read what it represents, making the estimate harder to interpret.
Cause and investigation
Hypothesis: a light foreground intended for a dark surface is applied to a pale card. The computed color is confirmed; the originating style or token is unverified.
Steps to reproduce
1. As Admin, open /trips/new at 1440 × 900.
2. Inspect the final row of the Ước tính card, below Tiền kết hợp. Compare the faint Lợi nhuận dự kiến label with the visible green +0 amount; repeat at tablet width.
Acceptance criteria
1. Use at least 4.5:1 contrast for the normal-size label against the rendered background, including any transparency.
2. Keep label and amount readable together for zero, positive and negative estimates. Do not change calculation or sign formatting as part of the styling fix.
3. Verify every estimate label at desktop, tablet and any phone state that exposes the summary. Preserve readable typography and compact spacing.
4. Check shared summary text styles on both pale and dark surfaces so repairing this label does not make another variant unreadable. Keep financial labels accessible in the document structure.
Requirement reference
Fresh settled staging screenshot and browser-owner computed-color inspection.
