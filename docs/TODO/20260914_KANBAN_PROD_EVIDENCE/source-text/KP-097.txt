Align financial policy messages with approval state

Environment: Staging https://vantai.tingting.vip
Reviewed: 14 September 2026
Role: Admin; desktop 1440 × 900
Page: /config/app-settings — Chính sách báo cáo and Hồ sơ tài chính xe
Existing behaviour
Submitting the first reporting policy at 15% for September 2026 shows current version 1 and Lịch sử đã duyệt. Yet feedback says Đã gửi yêu cầu. Cấu hình hiện tại chưa thay đổi. Creating vehicle 15C-167.31's financial profile also updates current version and history immediately beside the same unchanged-configuration message.
Target behaviour
Make confirmation and feedback match the resulting policy state. If initial Admin creation intentionally approves immediately, state that before confirmation and report approval afterward. If it only requests approval, retain the current policy and show the pending request.
Impact
Administrators cannot tell whether the policy is current or awaiting approval, leading to unnecessary waiting or repeat submissions.
Cause and investigation
Initial creation may differ from the workflow described by shared feedback. Verify the rule and returned state; implementation and approval authorization were not inspected.
Steps to reproduce
1. As Admin, create the first reporting policy at 15% for the current open month. Select Tạo yêu cầu đầu tiên and confirm Gửi yêu cầu.
2. Compare the unchanged-configuration message with current version 1 and Lịch sử đã duyệt.
3. Repeat via Hồ sơ tài chính xe with a vehicle's first valid monthly profile. Compare its updated current version and history with the same message.
Acceptance criteria
1. Define the initial-policy outcome and label the confirmation accurately before the user commits.
2. Both tabs report the resulting state and effective date accurately; changed current versions never receive an unchanged-configuration message.
3. Pending and approved outcomes are distinct, with a valid next step when approval remains necessary. Preserve the existing permissions and closed-period constraints.
4. Retest first-policy creation, subsequent requests and rejected duplicate effective months. Verify readable feedback on phone, tablet and desktop.
Requirement reference
Staging Chrome audit, 14 September 2026. User requirement: clear, reliable feedback for every workflow.
