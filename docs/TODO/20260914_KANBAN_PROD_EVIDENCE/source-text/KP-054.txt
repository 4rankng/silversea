Existing behaviour
Under Số cont TSTU4182600, the summary line reads ‘20’DC · 20DC’. Two visually different spellings of the same apparent container type are displayed side by side without labels that distinguish them.
Target behaviour
Show one consistently formatted container-type value in the driver summary. If the two values actually represent different business concepts, use distinct descriptive labels rather than presenting them as an unexplained duplicate.
Impact
The repeated value adds noise to a compact mobile card and can make drivers wonder whether the two codes have different meanings.
Cause and investigation
Hypothesis only: the summary may concatenate a formatted type label with its raw code. Inspect the fields before removing either; this visual review does not prove their backend semantics.
Steps to reproduce
1. On 13 September 2026, sign in to staging as bqhuong and open /my-trips/20 in Chrome at 390 × 844.
2. Collapse Thông tin lệnh and Thông tin xuất hóa đơn, then find SỐ CONT & SEAL.
3. Read the line directly below TSTU4182600: 20’DC · 20DC.
Acceptance criteria
1. TSTU4182600 displays one canonical container-type value without an equivalent raw-code duplicate.
2. If the values are semantically different, each is clearly labeled and both remain available.
3. Other supported container types render consistently without losing container number, seal or edit controls.
Requirement reference
Visual review on 13 September 2026 — driver detail /my-trips/20. Related design intent: 20260912_6.docx calls for a consistent, clear detail presentation; no explicit requirement for this duplicate value was found.
