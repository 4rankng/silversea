Remove the internal dashboard version label from the main summary
QA-033 | P3 | Enhancement | TODO
Environment: Staging https://vantai.tingting.vip
Reviewed: 14 September 2026
Role: Administrator (admin); Chrome mobile viewport 390 × 844
Page: https://vantai.tingting.vip/dashboard
Existing behaviour
The dashboard refresh line shows a timestamp followed by executive-dashboard-v1. This internal-looking identifier appears in the normal Dòng tiền & đối soát summary on desktop and mobile without an explanation of its relevance to the administrator.
Target behaviour
Keep the useful refresh timestamp and data-completeness status in plain language. Remove the technical version identifier from the normal summary, or place it in an explicit diagnostics view if it is needed for support.
Impact
The unexplained identifier adds visual noise to a compact financial summary and makes the screen feel unfinished.
Cause and investigation
Hypothesis: a dashboard implementation or source identifier is being exposed in shared status copy. Confirm its purpose before adjusting presentation; no data-quality failure is inferred.
Steps to reproduce
1. Open Tổng quan Quản trị as admin and locate Dòng tiền & đối soát.
2. Read the refresh line beneath the financial figures on desktop or mobile.
Acceptance criteria
1. The normal dashboard summary no longer displays executive-dashboard-v1 or a comparable unexplained internal version token.
2. The refresh timestamp and meaningful data-completeness warnings remain visible and accurate.
3. Any support identifier remains available only through deliberate diagnostic access, if required.
4. The compact layout remains readable at mobile, tablet and desktop widths.
Requirement reference
Exploratory staging review, 14 September 2026.
User direction: professional, compact, data-heavy UI across desktop, tablet and mobile.
