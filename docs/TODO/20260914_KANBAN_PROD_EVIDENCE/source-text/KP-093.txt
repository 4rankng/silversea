Existing behaviour
Clicking Ops phụ trách for 15H-021.39 renders the dialog as plain inline content below the vehicle table. There is no distinct dialog card or backdrop, the close icon is a tiny standalone ×, and the footer actions appear joined as ĐóngLưu without visible button boundaries. The selector stretches across the content area. Reopening after reload retains this presentation. Tablet and phone show the same inline layout and unstyled footer.
Target behaviour
Use the app’s compact dialog and button pattern for Operations ownership: a bounded surface above the page, clear vehicle identity, readable form spacing and distinct close/save controls.

The component uses .ops-modal-backdrop + .ops-modal classes with position:fixed, z-index: var(--z-modal), and styled btn-primary/btn-secondary buttons. Guard test ops-modal.styles.test.ts (10/10) validates the pattern.
