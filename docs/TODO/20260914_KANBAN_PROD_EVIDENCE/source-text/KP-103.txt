Existing behaviour

Editing 15H-021.39 exposes only plate and activity status, with no ownership setup. This was confirmed as both Manager and Admin. The monthly 60/40 shareholder split is correct; it does not resolve the vehicle ownership requirement.
Target behaviour
Link each blocked vehicle to an authorized ownership editor, or provide that setup at the linked destination. Support effective-dated partner ownership under defined business rules, then let users return and refresh the preview. Preserve the guard against distributing profit without valid ownership.
Impact
The prescribed recovery path cannot resolve the blocker, leaving the displayed quarterly profit undistributable.
Cause and investigation
The warning and linked editor appear misaligned. Existing Admin fleet captures also show no ownership fields; an unvisited editor may still exist.

1. At /profit, preview Quý 3 / 2026 and observe the missing-ownership warning for 2,000,000 VND.
2. Follow Cấu hình → Xe → Sở hữu, then edit 15H-021.39 in /config/trucks.
3. Observe the plate/status-only form; repeat as Admin and confirm there is no ownership action.
