# Frontend UI audit — 2026-10-16

**Scope.** Code-read audit of every page module in `frontend/src/pages/` (66 route
modules + 5 shared page components) and their feature-owned CSS in
`frontend/src/features/`, grading against the five problem classes the operator
flagged on the "Tạo lô hàng" create-shipment screen: (1) mobile collapse,
(2) control consistency, (3) visual hierarchy, (4) design-system drift,
(5) density. **Excluded:** `pages/clerk/ClerkShipmentCreatePage.*` and
`features/shipments/create/` — that screen's design fix is already in flight on
`design/shipment-create-mobile-ux` and is used here only as the approved
reference (patterns A–E below).

cites file:line read from this worktree at commit `388cd119`. No browser was
driven; nothing here is a UI-DRIVEN claim. Each wave must produce its own
