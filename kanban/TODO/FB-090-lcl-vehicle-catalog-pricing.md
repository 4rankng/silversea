# FB-090: LCL — Loại xe tải trọng tải + Bảng giá thu/trả theo trọng tải
**Nguồn:** DEV SPEC Hoàn thiện Hàng lẻ (LCL) 2026.10.15, §I + §II.1 (docx 2026.10.15_Cap_nhat_luong_hang_le)
**Ưu tiên:** P0 (foundation — mọi ticket LCL khác phụ thuộc)
- Mở rộng Danh mục Loại xe: thêm trọng tải xe tải (1.25T, 2.5T, 3.5T, 5T, 8T, 10T, 15T) bên cạnh Cont 20'DC/40'DC/40'HC
- Bảng giá (Tuyến × KH/Nhà thầu): cấu hình Cước thu khách + Cước trả nhà xe theo từng mức trọng tải (bên cạnh giá cont hiện có)
- Quy tắc: Hàng lẻ Xe tải = 100% Xe ngoài; Hàng lẻ Cont 20'/40' = Xe nội bộ hoặc Xe ngoài
