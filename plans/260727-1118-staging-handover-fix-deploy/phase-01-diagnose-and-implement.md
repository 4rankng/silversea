# Phase 01 — Diagnose and implement

## Work

- Reproduce and trace each confirmed failure to its source.
- Compare with working endpoint, RBAC, and auth patterns.
- Add failing regression tests before applying minimal root-cause fixes.
- Keep backend portal/settings, frontend customer auth, and M01-1.7 ownership
  isolated during parallel work.

## Exit

- Root-cause report exists for each defect group.
- Changes are scoped and tests cover the corrected behavior.
